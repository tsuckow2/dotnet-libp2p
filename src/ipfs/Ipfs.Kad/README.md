# Nethermind.Ipfs.Kad

The Amino Kad DHT (`/ipfs/kad/1.0.0`, née `/ipfs/kad-dht/1.0.0`)
for .NET, on Nethermind libp2p: a routing client — iterative
FIND_NODE / GET_PROVIDERS walks over a peer book, starting from the
public bootstrap set — plus the protocol half that answers queries
from a static table, for tests and small nodes.
